
| Acronimo o palabra   | Definición                                                                                                                                     |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `DMZ`                | Zona desmilitarizada                                                                                                                           |
| `RFC 1918`           | Rango de redes privadas                                                                                                                        |
| `Red bogon`          | dirección IP no asignada y que no ha sido asignado a nadie en la red publica                                                                   |
| `GI0/0`              | Interfaz gigabit                                                                                                                               |
| `DHCP`               | Dynamic Host Configuration Protocol                                                                                                            |
| `CIDR`               | Classless Inter-Domain Routing                                                                                                                 |
| `Inter vlan routing` | Es un enrutamiento a través de una vlan a otra con etiqueta diferente, puede ser mediante un router o un switch de capa 3                      |
| `APIPA`              | Automatic Private IP Addressing, es una dirección privada temporal cuando no hay un servidor dhcp en el rango de 169.254.0.1 - 169.254.255.254 |
| `IANA`               | `Internet Assigned Numbers Authority`                                                                                                          |
